# Supervised Machine Learning Algorithms

A broad collection of supervised machine learning notebooks covering regression, classification, ensemble learning, regularization, and applied mini-projects.

## Overview
This repository is a learning and practice hub for supervised ML. It includes standalone algorithm notebooks and domain-focused prediction projects.

## Repository Highlights
Core algorithm notebooks:
- `Linear_regression.ipynb`
- `Logisticregression.ipynb`
- `KNN.ipynb`
- `SVM.ipynb`
- `DecisonTree.ipynb`
- `DecisionTreeRegressor.ipynb`
- `DecisionTreeRevised.ipynb`
- `NaiveKnn&CV.ipynb`

Project folders:
- `Student-Score-Prediction/`
- `Titanic Survival prediction/`
- `HousePricePrediction/`
- `HeartAttackPrediction/`
- `EmployeeResignPrediction/`
- `Regularisation/`
- `bagging&boosting/`

Datasets included:
- `Iris.csv`
- Multiple project-specific CSV files in subfolders

## Topics Covered
- Regression and classification fundamentals
- Model evaluation and validation
- Regularization (Lasso, Ridge)
- Bagging and boosting concepts
- Applied use cases across different datasets

## Tech Stack
- Python
- Jupyter Notebook
- Pandas, NumPy
- Scikit-learn
- Matplotlib / Seaborn

## Getting Started
1. Clone the repository.
2. Create a Python environment and install dependencies.
3. Start with core notebooks, then move to project folders.
